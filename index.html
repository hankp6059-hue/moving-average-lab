美人蕉降噪实验：三种传统滤波对比

用手机拍的一张美人蕉照片，转成灰度后加上 σ=25 的高斯噪声，再分别用高斯滤波、中值滤波、双边滤波去噪，用 PSNR 和 SSIM 打分。所有计算都在浏览器里实时完成，可以随意调参数，也可以换成你自己的照片。

结论

看起来干净，不等于细节真实

双边滤波的 SSIM 最高（0.821），平坦区也最干净；但在梯度最大的 20% 像素（花瓣纹路、石板裂缝）上，它的 PSNR 反而最低：26.85 dB，比高斯滤波的 28.37 dB 低了 1.5 dB。

复现

Python 原始代码

仓库里的 denoise_experiment.py 就是原实验代码，网页的默认参数和它完全一致。运行环境：Python 3.13、OpenCV 5.0、scikit-image 0.26。

pip install -r requirements.txt
python denoise_experiment.py

    
网页里的噪声用和 numpy 一样的随机数算法（MT19937 + 极坐标法）生成，种子为 0 时与 np.random.seed(0) 得到的噪声逐像素相同；高斯滤波和中值滤波按 OpenCV 的定点算法实现，结果与 OpenCV 逐像素一致；双边滤波只有极少数像素差 1。SSIM 与 scikit-image 默认设置一致（7×7 均匀窗口）。
